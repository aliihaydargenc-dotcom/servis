# Veri Kaynakları

- Hava: Open-Meteo Forecast API.
- Trafik: TomTom Traffic API; kullanıcı ücretsiz anahtarını cihazda girer.
- Haber: TRT Haber resmî RSS akışları.
- Döviz: TCMB günlük XML.
- BIST: uygulama gerçek zamanlı veri dağıtmaz; resmî Borsa İstanbul sayfasına yönlendirir.
- Radyo: Radio Browser açık istasyon dizini + istasyonların kendi HTTPS stream'leri.
- Nöbetçi eczane: Antalya Eczacı Odası resmî sayfası; API credential gerektirdiği için client'a gömülmez.

Dış kaynaklar hata verdiğinde UI eski veriyi canlıymış gibi göstermemelidir.
